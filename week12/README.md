# 12주차 성적 데이터 분석

## 데이터 출처
수업에서 배부된 scores_2026.csv를 사용

## 데이터 크기
원본: 114행
정제 후: 100행
열 수: 5개

## 열 설명
학번: 학생의 학번
이름: 학생의 이름
반: 학생이 속한 반 (앞뒤 공백 제거 후 1반, 2반으로 정리)
과목: 수강 과목 (앞뒤 공백 제거 후 수학, 영어, 프로그래밍으로 정리)
점수: 해당 과목의 점수 (유효 범위 0~100)

## 데이터 정제 기준
점수가 비어 있는 행은 삭제하였다.
모든 열의 값이 완전히 같은 중복 행은 하나만 남겼다.
반과 과목 값의 앞뒤 공백을 제거하였다.
점수가 0 미만이거나 100을 초과하는 행은 삭제하였다.

점수가 비어 있는 행은 실제 점수를 알 수 없어 임의로 채우면 분석 결과가 달라질 수 있으므로 삭제하였다.

## 정제 결과
시작: 114행
빈칸 6행 제거 후: 108행
중복 4행 제거 후: 104행
범위 밖 점수 4행 제거 후: 100행

## 분석 결과
1반 전체 평균: 78.24점
2반 전체 평균: 71.44점
전체 평균은 1반이 6.80점 높았다.
과목별 평균은 프로그래밍, 영어, 수학 모두 2반이 높았다.

반 전체 평균과 과목별 평균의 결론이 다른 이유는 두 반의 과목별 인원 구성이 다르기 때문이다.

그룹별 인원수 합계와 정제 후 행 수: 100으로 일치
